# Museum date site

Put your files here:
- `sounds/yes.mp3`  -> plays when she/he taps Yes
- `sounds/no.mp3`   -> plays on every No
- `images/museum.jpg` -> picture shown in the gold frame (optional, falls back to the drawing)

Edit the museum name, date, place at the top of `index.html` (the CONFIG block).
Deploy: push this folder to GitHub, then import the repo in Vercel (Framework: Other).
